**Core:** With `store_frames` on, each camera's metric depth (`extra["<camera>_depth"]`, a 2-D float array or a zero-argument callable) is resolved once per observation and saved as float32 under `frames/<run>/depth/`. The stored trial drops those keys. `inspect-robots video` still reads only the RGB frames in the run directory. A safety or hardware halt from a depth callable stops the run. An action that already completed stays in the trial, with its RGB frames and its action-log row.
