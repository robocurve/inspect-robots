Frames from distinct trial and camera identities no longer overwrite each other: new frames use a versioned, reversibly encoded filename, and frames written under the old naming remain readable. A new write whose encoded path exceeds the filesystem limit now fails with the filesystem error instead of colliding. `inspect-robots video` output names follow the new frame names (e.g. `~f1~scene-0-e0~left_cam.mp4`); quote them in shells, since a leading `~` triggers tilde expansion.
