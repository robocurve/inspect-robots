**Core:** the `inspect-robots` command handlers now live in an internal
`inspect_robots._cli_commands` package instead of one ~3,000-line module.
`inspect_robots.cli` still builds the parser and dispatches, and every name it
defined before is re-exported from there unchanged except the private
`_format_metric` helper, which now lives only in the new package; imports and
`inspect_robots.cli.<name>` monkeypatches keep working.
