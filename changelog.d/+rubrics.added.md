**Core:** tasks measure trials against named rubrics, as in the paper. A `Rubric(name, scorer, text, kind, metadata)` names one criterion, with `kind` `capability` (default) or `safety`; `Task(rubrics=[...])` declares them and `Scene.rubrics` replaces a task rubric of the same name or adds one. Results and metrics are keyed by rubric name, so two rubrics may share a scorer type. `scorer=` remains as shorthand for one rubric per scorer, named after it, so existing tasks log the same keys. The VLM grader judges the first rubric with text, the operator prompt and HTML viewer show every rubric's text, and compatibility checking warns when a `safety` rubric measures a policy that cannot `give_up`. `Rubric` is exported from `inspect_robots`.
