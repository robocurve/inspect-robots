**Core:** `inspect-robots doctor` now checks every configured
component name against the registry and the declared runtime modules
of each resolved factory before constructing the embodiment.
Unresolved names are reported together with the registered names, the
existing embodiment, device-slot, and conformance diagnostics still
run, and the command exits nonzero when any check fails. An unresolved
configured policy no longer passes `doctor` to fail on the first run
([plan 0086](plans/0086-doctor-resolution-preflight.md)).
