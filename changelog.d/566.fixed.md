**Core:** approval details are no longer limited to the built-in `clamped` / `delta_clamped` flags. When an approver modifies an action, the rollout now also reports the meta keys it *newly* sets to a truthy value relative to the action it reviewed (string values render as `key=value`), so third-party approvers — e.g. a collision approver holding an arm — can explain their intervention to the policy via `observation.extra["approvals"]` instead of surfacing `detail: None`.
