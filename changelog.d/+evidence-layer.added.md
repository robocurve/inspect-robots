**Core:** `inspect_robots.evidence` and `inspect-robots compare` report how far
to trust a saved run and whether one run beat another: scene-clustered bootstrap
intervals, trial coverage, scene-paired sign and permutation tests with Holm
correction, a minimum detectable effect and scene planner, and an anytime-valid
sequential test that stays valid when results are checked after every scene
([plan 0086](plans/0086-evidence-layer.md)).
